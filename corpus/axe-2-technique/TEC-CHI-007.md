::Un losange rouge sur un bidon, une plaque orange sur un camion : ce sont des phrases complètes pour qui sait les lire. Elles disent ce qui brûle, ce qui ronge, ce qui empoisonne, et ce qu'il ne faut pas faire.::

## Les neuf pictogrammes

Un losange à bord rouge, un symbole noir :

| Symbole | Danger |
|---|---|
| Bombe qui explose | Explosif |
| Flamme | Inflammable |
| Flamme au-dessus d'un cercle | Comburant : fait brûler plus fort ce qui brûle |
| Bouteille de gaz | Gaz sous pression |
| Liquide qui ronge une main et une surface | Corrosif : brûle la peau, les yeux, le métal |
| Tête de mort | Toxique : peut tuer à faible dose |
| Point d'exclamation | Irritant, nocif, ou dangereux pour la couche d'ozone |
| Silhouette avec une étoile sur la poitrine | Danger grave pour la santé : cancer, malformations, allergie respiratoire |
| Arbre mort et poisson | Dangereux pour l'environnement |

**Le mot d'avertissement** : **« Danger »** pour les produits les plus dangereux, **« Attention »** pour les autres.

**Les phrases** : les **mentions H** décrivent le danger (H2 pour les dangers physiques, H3 pour la santé, H4 pour l'environnement) ; les **conseils P** disent comment se protéger et quoi faire en cas d'accident.

## La fiche de données de sécurité

Tout produit professionnel a une fiche de 16 rubriques. Les plus utiles en urgence :

- **Rubrique 2** : les dangers ;
- **Rubrique 4** : les premiers secours ;
- **Rubrique 5** : comment éteindre un feu de ce produit ;
- **Rubrique 7** : comment le stocker ;
- **Rubrique 8** : quelles protections porter.

## La plaque orange des camions et des citernes

Deux nombres, l'un au-dessus de l'autre :

- **en haut, le code danger** : le premier chiffre dit le danger principal (2 gaz, 3 liquide inflammable, 4 solide inflammable, 5 comburant, 6 toxique, 8 corrosif). Un chiffre doublé renforce le danger (33 : très inflammable). **Un X devant : ne jamais mettre d'eau.**
- **en bas, le numéro ONU** de la matière.

Quelques numéros courants : **1203** essence, **1202** gazole, **1965** gaz de pétrole liquéfié, **1005** ammoniac, **1017** chlore.

**Un accident de camion avec plaque orange** : on s'éloigne, contre le vent, et on donne les deux nombres aux pompiers au téléphone. Ils savent immédiatement ce qu'il y a dedans. Voir [[SURV-CRI-006]].

## Ce qu'on en retient

- **Pas de pictogramme ne veut pas dire sans danger** : l'eau de Javel, l'essence et les médicaments tuent aussi.
- **Deux pictogrammes différents** sur deux produits : on ne les mélange pas. Voir [[TEC-CHI-006]].
