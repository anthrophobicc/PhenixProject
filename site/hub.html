Publish your version

  1. Start from the official version: download it above, or open Phenix Base.
  2. Translate, adapt, add your sheets, in Phenix Base or in any text editor.
  3. Export it: Phenix Base › Modules › Phenix Hub › Create my version.
  4. Send it here. The team checks it is what it says it is, then it shows up for everyone.

The file Phenix Base exports with “Create my version”, or a map or layer exported from the Maps view. 25 MB at most.

By sending, you agree that your version may be shared under the CC BY-SA 4.0 licence, like the official one.

Using a downloaded version

  • In Phenix Base, on a phone or a computer: drop the file on the window, or go to Modules › Phenix Hub › Open a version file. Then choose the version you read. Your own sheets are never touched, and the official version is always one tap away.
  • Anywhere else: it's plain JSON with the text of each sheet in Markdown. Any device, any program can read it, today and in twenty years.
  • Keep a copy on a USB stick or an SD card. That's the whole point: knowledge that doesn't depend on a server.
