Comment écrire une bonne fiche

Le ton

Assertif. Vouvoiement. Aucune phrase pour combler, aucun sensationnalisme. Phrases courtes dans l'urgence, longues dans l'explication.

Les deux structures

Sujet urgent — Agir, puis Adapter, puis Comprendre. Le lecteur n'a pas le temps : il exécute d'abord.

Sujet non urgent — Agir, puis Comprendre, puis Adapter. Le geste juste découle du mécanisme.

Écrivez les titres de section ainsi : ## AGIR, ## COMPRENDRE, ## ADAPTER.

La partie « Comprendre »

Expliquez le mécanisme, pas seulement le fait. Le lecteur doit pouvoir en déduire quoi faire dans un cas que votre fiche ne décrit pas. C'est ce qui sépare une fiche utile d'une liste d'instructions.

Les balises

Elles ne classent pas la fiche : elles orientent la lecture selon la situation de celui qui cherche.

  • Temps — Flash (minutes), Court (heures), Long (jours et plus)
  • Contexte — Seul, À deux, En groupe
  • Risque — Discret, Exposé
  • Matériel — Aucun, Récupération, Technique

Les sources

Préférez les sources primaires : organismes de santé, institutions scientifiques, manuels techniques, publications évaluées. Sur les sujets où une erreur blesse, une fiche sans source ne sera pas intégrée.

Les liens

Reliez votre fiche aux autres avec l'identifiant entre doubles crochets : [[URG-EAU-001]]. Placez-les dans le texte, là où le lecteur en a besoin. Une fiche isolée est un article ; une fiche reliée est un chemin.

Les sujets

Tous, tant que la qualité y est. Phenix n'est pas une base de survie : un moteur, une plante, une technique manuelle, une période historique, une méthode de cuisine ou d'architecture ont toute leur place.

Ce que la fiche traite, en clair. Pas de titre mystérieux.

Le texte complet. Utilisez ## AGIR, ## COMPRENDRE, ## ADAPTER pour les sections.
